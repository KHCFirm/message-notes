Message Notes

Hosted edition · version 1.0.1.0

Website setup and manifest download

Save a note on the selected email

Open a normal message in your own Microsoft 365 work or school mailbox. Select Apps > Message Notes. Use Outlook's pin icon to keep the sidebar open while switching emails. Enter a note and select Save note; wait for Saved. Ctrl+S also saves.

Clear text only clears the editor. Save afterward to remove the stored note. Reload reads the mailbox version and asks before discarding unsaved edits. Copy note copies the text, or selects it if clipboard access is blocked.

The installation succeeded, but there is no button

Open a normal received email in the exact mailbox used for installation, not a draft or a delegated mailbox. Check the Apps button on the message or More apps on the message ribbon, not just Outlook's left-side navigation apps. Refresh Outlook on the web and restart new Outlook after changing an installation.

In a connected Exchange Online PowerShell session, inspect the mailbox registration:

$Mailbox = Read-Host 'Mailbox email address'
Get-App -Mailbox $Mailbox |
    Where-Object { $_.AppId -eq '7c6010d9-3b66-45f7-86ca-296e175b2b86' } |
    Format-List DisplayName, Enabled, AppVersion, AppId

If it exists but Enabled is False, enable only that add-in for that mailbox:

Enable-App -Mailbox $Mailbox -Identity '7c6010d9-3b66-45f7-86ca-296e175b2b86'

If no record is returned, verify the mailbox address and how it was deployed. Get-App -Mailbox is not a complete inventory of add-ins deployed through Integrated apps. If installed by an administrator, check its user assignment in Microsoft 365 admin center. Do not disable organization security controls.

The button is present, but the sidebar does not load

Open the hosted setup page directly in your browser. The website and Microsoft Office.js CDN must be reachable. Download and install a new manifest after changing the website URL. Uploading files to GitHub does not replace a manifest that still points to localhost. A 404 or certificate error is a hosting problem; a missing button may instead be an installation, enablement, or activation-context problem.

Storage, privacy, and limits

Plain text notes use the original add-in ID and the messageNote custom property. The code saves on the selected message with Outlook's loadCustomPropertiesAsync / saveAsync APIs. It does not send note text to this website's host, and does not change the email body. The host receives ordinary requests for program files.

Mailbox metadata is not an encrypted private vault. Do not store passwords, credentials, or secrets. Public website hosting does not make the mailbox public, but protect who can change the hosted application code.

The text limit is approximately 2,200 characters, subject to the 2,500-character serialized custom-properties limit. Quotes, line breaks, and some other characters can use extra space. Saved notes are linked to individual messages, not a whole conversation.

There is no autosave. Unsaved drafts stay in memory only while the pane is open. Closing or reloading it can lose them. There is no all-notes search, version history, mobile interface, or backup system. Offline, shared/delegated mailbox, archive, copy/move, and protected-message scenarios have not been validated in your tenant.

A conflict check detects some concurrent changes, but Outlook custom properties do not provide an atomic compare-and-swap. Avoid editing the same note from several windows at once.

Pilot checklist

Verify that the website loads, the new manifest is installed and enabled for the intended mailbox, and the button appears on a normal received email in both web Outlook and new Outlook. Save a sample note, change messages, return, close/reopen the pane, and check from the second client. Confirm clearing a sample note works. Test your needed message move/archive behavior before relying on it.

Automated tests use simulated Office APIs; they do not establish that a live mailbox installation works. No live tenant installation or GitHub publication was performed when this package was created.
