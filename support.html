Using the note sidebar

Open a message in your Microsoft 365 mailbox and choose Apps > Message Notes. The sidebar contains only the note editor, formatting controls, Save button, and a small save-status indicator.

Formatting includes bold, italic, underline, font size, and text color. Pasted content is intentionally converted to plain text so that external email/web formatting and scripts are not stored in the note. Apply formatting after pasting if needed.

Autosave is enabled. After you stop typing or formatting for about 650 milliseconds, Message Notes attempts to save the current note. It also attempts an immediate save when focus leaves the editor. The Save button remains available as a manual fallback, and Ctrl+S also saves. The small status indicator shows Saving, Saved, or Save failed.

If you continue typing while a save is in progress, the newer text remains editable and is queued for the next autosave rather than being overwritten by the earlier save.

Existing notes

Version 1.1 automatically reads notes saved by the original plain-text version. Existing notes remain attached to the same individual messages. The first time an older note is changed and saved, it is stored in the new rich-text format.

Storage and privacy

Notes use the same messageNote custom property on the selected Outlook message. The application does not put the note in the email body, browser local storage, or a GitHub database. GitHub Pages hosts only the static program files.

Outlook custom properties have a small serialized storage limit. Rich formatting consumes some of that space, so heavily formatted notes may reach the limit sooner than plain text. If this happens, the sidebar shows an error and does not truncate the note.

Mailbox metadata is not an encrypted private vault. Do not store passwords, credentials, or secrets in Message Notes. Protect repository write access because changed JavaScript would execute with the add-in's mailbox-item permissions.

Saving and message changes

Autosave greatly reduces the chance of losing a draft, but Outlook does not provide a guaranteed pre-switch event before every message change. If you type and instantly switch to another email before Outlook completes the write, return to the original message and use Save if the status did not reach Saved.

The add-in still checks that the selected message has not changed before writing, which prevents a delayed save from being attached to the wrong email.

Troubleshooting

If the sidebar does not load, first confirm the GitHub Pages site is reachable and that the mailbox still shows Message Notes as enabled. If saving fails, keep the pane open, wait for connectivity to recover, and select Save again. If a concurrent-edit conflict is detected, the sidebar exposes a Reload saved note action instead of overwriting the other copy.

Shared/delegated mailbox, protected-message, archive, copy/move, offline, and mobile scenarios should be tested before relying on them in production.
